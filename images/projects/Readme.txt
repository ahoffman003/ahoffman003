Put project screenshot images in this folder.

HOW TO USE:
1. Add your image file here, e.g. images/projects/sweet-sorghum.jpg
2. Open projects-data.js
3. Find the matching project entry and set:
       image: "sweet-sorghum.jpg"
   (just the filename — not the folder path)
4. Save and refresh the page.

If a project's "image" field is left blank (""), the card will show a
generated decorative pattern instead of a broken image, so it's fine to
publish a project before you have a screenshot ready.

Recommended image specs:
- Roughly 4:3 or wider (landscape), at least 1000px wide
- JPG or PNG, ideally under ~500KB so the page stays fast to load
- The image is cropped to fill the card, so keep the important part
  of the screenshot centered
